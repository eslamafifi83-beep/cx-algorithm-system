5. New episode checklist

You only upload to Spotify for Creators. Your feed (https://anchor.fm/s/10dcc5b9c/podcast/rss) does the rest for the apps; only your website and YouTube need you.

Automatic, nothing to do (usually within a few hours to a day): Apple Podcasts, Amazon Music, iHeartRadio, Audible, Pocket Casts, Castbox, Overcast, Goodpods, Deezer, TuneIn, Pandora and SiriusXM all read the feed. The sign-ups were one-time.

Each new episode:

  • Spotify for Creators: upload, write the description (it feeds every app and your website's notes), publish. Never write "weekly".
  • Website, about 5 minutes: admin → Episodes → add an episode → paste its Spotify link → Fetch (title and cover) → Fill empty fields from the website (notes, "What you'll learn", date, length) → add the guest name → Save & publish. The episode gets its own page at thecxalgorithm.com/episodes/<title-in-lowercase-with-dashes>, the sitemap updates and Bing is pinged automatically. Give it about 90 seconds to show.
  • Homepage: admin → Home page → tick the new episode in "Fresh this season" (and untick the oldest) so the newest three lead the homepage. The hero's "Latest episode" card follows the last episode automatically.
  • New guest: admin → Guests → add a card (name, title, company, photo, bio, episode number and link, LinkedIn). If their company is new, add its logo in admin → Companies first.
  • Link back in Spotify (recommended): once the website page exists, edit the Spotify description and add at the end: Full episode notes, transcript and chapters: thecxalgorithm.com, linked to the episode's page. In the editor's HTML view, switch back to the normal view before Save, or the change is lost.
  • Transcript, chapters, takeaways, guest quote: not automatic. Open Claude Code in the project folder and ask it to "add the transcript for the new episode". It runs the same process as the first 8 and gives you a page to review before publishing.
  • YouTube: upload the video yourself to @TheCXAlgorithmPodcast.
  • Optional: Google Search Console → "Inspect any URL" → paste the new episode page → Request indexing, so Google finds it within a day instead of a week.
  • Share it: LinkedIn and your newsletter as usual.

Design lives in the code. The workflow is always the same three steps:

7. Things that will bite if forgotten ⚠️

  • Git author identity: code pushed to GitHub must be authored as 298448529+eslamafifi83-beep@users.noreply.github.com or Vercel blocks the deployment ("commit author does not have access"). This is already configured inside the project folder — but if the project is ever copied to a new computer, set it again first thing.
  • Don't delete vercel.json: it pins the project type ("Other") — without it Vercel hunts for a server file and the build fails with "No entrypoint found."
  • Never commit .env: it's git-ignored on purpose. The one on your machine currently holds a dead (rotated) key — harmless.
  • Cloudflare's orange cloud: DNS records pointing at Vercel must stay gray ("DNS only"). Turning them orange breaks the site.
  • Domain renewal: thecxalgorithm.com renews yearly (~$11) — keep Auto-Renew ON and your card valid in Cloudflare, or the site (and email) go dark.
  • Episode addresses come from titles: each episode's page address is made from its title. If you rename an episode, its address changes; links shared before still work when the new title starts the same way, otherwise they show the "page not found" page. So try to settle a title before sharing the link.
  • Image optimiser allowance: Vercel's free plan includes 5,000 image resizes a month. Each image is resized once and then reused for 31 days, so this site uses a small fraction of that.
  • Vercel free plan is for non-commercial use — fine for the podcast; if you start selling sponsorships through the site, upgrade to Pro (~$20/mo).

8. If something breaks — first aid

SymptomDo this
Site is down / broken after a changeVercel → Deployments → find the last working deployment → ⋯ menu → "Promote to Production" (or "Instant Rollback"). Instantly restores the previous version.
Forgot admin passwordVercel → Settings → Environment Variables → edit ADMIN_PASSWORD → save → Deployments → Redeploy.
Edits in admin don't appear on the siteWait ~30 seconds and hard-refresh (Ctrl+Shift+R) — pages briefly cache content.
Deployment "Blocked — commit author…"The git identity issue above. Re-set the author email in the project folder.
Email to hello@ not arriving in GmailCheck Cloudflare → Email Routing is still Active and its MX/TXT records exist. Also check Gmail's Spam folder.
Can't send as hello@ from GmailGmail → Settings → Accounts and Import → "Send mail as" — if it shows an error, create a fresh App Password (myaccount.google.com/apppasswords) and re-enter it via "edit info".
Spotify auto-fill only fills title + coverThe Spotify keys aren't being read: check both env vars exist in Vercel (spelled exactly SPOTIFY_CLIENT_ID / SPOTIFY_CLIENT_SECRET), then Redeploy.
Anything elseOpen Claude Code in the project folder and describe/screenshot the problem — the project history is in its memory.
